# BTM Layout Wellness Spa

A modern luxury spa landing page for BTM Layout Wellness Day & Night Spa, built with plain HTML, CSS, and JavaScript.

## Features

- Full spa landing page layout
- Premium dark luxury color palette
- Service cards for massage and wellness treatments
- Gallery with lightbox modal
- Direction and map section
- Booking modal connected to WhatsApp
- Floating WhatsApp and call buttons
- Responsive layout for mobile and desktop

## Project Structure

```bash
BTM layout wellness(spa)/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/ (optional for future images/icons)
```

## How to Run

1. Open `index.html` in your browser, or
2. Run a local server from this folder:

```bash
python -m http.server 8000
```

Then open:

```bash
http://localhost:8000
```

## Customization

Update the contact details and WhatsApp number in `script.js`:

```js
const SPA_CONFIG = {
  phone: "+918097369137",
  whatsappPhone: "918097369137"
};
```
